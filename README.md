# Phishing Awareness Training Module

An interactive web-based cybersecurity awareness program designed to educate users about phishing attacks, social engineering, suspicious emails, fake login pages, and fraudulent websites.

## Features

- Phishing awareness introduction
- Suspicious email identification
- Fake login page awareness
- Fraudulent website awareness
- Social engineering techniques
- Practical security tips
- Real-life phishing case studies
- Interactive 5-question quiz
- Automatic quiz score calculation
- Reference links to cybersecurity resources
- Responsive web design

## Technologies Used

- HTML5
- CSS3
- JavaScript
